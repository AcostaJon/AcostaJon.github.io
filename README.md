# Personal Portfolio 🚀

A modern, responsive single-page developer portfolio built to showcase technical skills, featured projects, social links, and a contact section. Designed for speed, accessibility, and smooth user navigation.

---

## ✨ Key Features

- **About Section & Skills:** Brief professional introduction, summary of expertise and Visual breakdown of technical proficiencies and development tools.
- **Featured Projects:** Highlights of recent applications, including live demo links, source code repositories, and tech stack details.
- **Contact Form:** Interactive contact section for recruiters, clients, and collaborators to reach out directly.
- **Social Integration:** Direct access to GitHub, LinkedIn, and external social profiles.
- **Fully Responsive Layout:** Optimized mobile-first design using Bootstrap grid and custom UI components.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (React)
- **Styling & UI:** [Bootstrap](https://getbootstrap.com/) & Custom CSS
- **Icons:** [Bootstrap Icons](https://icons.getbootstrap.com/)
- **Deployment:** Vercel
